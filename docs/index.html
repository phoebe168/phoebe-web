從飲食開始，
讓健康成為生活的一部分

非比營養諮詢中心是新竹的營養師團隊。我們陪長照家庭、照護機構、社區與企業，把營養落實到每天的餐桌上。

我們做的事

  • 全齡營養

    從孩子到長輩，依身體狀況和生活習慣，調整成吃得到、做得到的飲食。

    營養評估體質諮詢術前術後免疫失調

  • 營養講座與合作

    到社區、學校、企業開講，也和照護機構合作規劃團膳。

    社區活動企業講座機構團膳合作

  • 長照營養

    長輩咀嚼、吞嚥變差，不代表只能吃打碎的食物。我們教照顧者調整質地，讓長輩吃得下也吃得好。

    銀髮族營養營養調理吞嚥營養指導

  • 健康管理

    減重、增肌或想改善檢查數字，用可以長期維持的方式慢慢調整。

    減重增肌健康管理

怎麼開始

  1. 加 LINE 說明需求

    簡單說明想諮詢的事情，或講座的主題、人數、時間。

  2. 初次評估

    營養師了解飲食習慣、身體狀況和生活作息。

  3. 規劃方案

    依評估結果，提出做得到的飲食建議。

  4. 追蹤調整

    定期回顧執行情形，視狀況修正。
